# ADR-0001: Use Event Copilot as the working product name

Status: Accepted  
Date: 2026-07-24  
Deciders: Team

## Context

The planning documents use Conference Connector, EventROI, and Event Copilot.
A single current name is required for fixtures, UI copy, and the presentation.

## Decision

Use **Event Copilot** as the working product name. Treat Conference Connector
and EventROI as historical concept names, not separate products.

## Consequences

- New specs and implementation use Event Copilot.
- Existing planning files remain unchanged as design history.
- A later brand change updates product-facing names but does not rename stable
  requirement or schema IDs.
